# «Читай людей»: Telegram Mini App (квиз из 5 ситуаций + PRO-модули)

Лёгкий Mini App без сборки: HTML + ES-модули, данные в `chitay_quiz.json`. Сервера нет, всё считается на устройстве.
Сервис 16+; ситуации «Отношения» (Q1, Q4) только после подтверждения 18+.

## Что внутри
| Файл | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js` | Каркас, тема (тёмная по умолчанию, светлая по настройке Telegram), главная с плитками, возраст 16+ |
| `quiz.js`, `engine.js` | Квиз из 5 ситуаций и режим «Калибровка» (после действия спрашивает уверенность); очки и статусы |
| `anatomy.js`, `figures.js` | «Анатомия невербалики»: SVG-схемы, метки, нижняя панель из 4 слоёв, мини-тренажёр, «Атлас» |
| `calib.js` | Чистая логика калибровки: уверенность 55/75/95 %, разрыв, оценка Брайера, минимум 10 ответов |
| `sheets.js` | «Шпаргалки»: свидания (только 18+ с самоподтверждением), переговоры (+ ссылка на калибровку), защита от давления (бесплатное ядро + паттерны и НЛП-мифы; кнопка «Помощь» всегда доступна) |
| `access.js` | Слой доступа (`hasAccess`, сроки `exp`) |
| `paywall.js`, `billing.js`, `pricing.js` | Экран тарифов (149/349/990 ⭐, разово), оформление с проверкой на сервере; пока `apiBase` пуст, это заглушка без списаний |
| `store.js`, `ctx.js`, `help-view.js` | Хранилище с запасным вариантом в памяти, общие помощники/навигация, экран помощи (всегда бесплатный) |
| `chitay_quiz.json`, `chitay_pro.json` | Данные: 5 кейсов; **открытая часть PRO**: бесплатная зона анатомии целиком, «каркас» остальных 10 зон, заголовки шпаргалок, бесплатное ядро защиты. Платных текстов здесь нет |
| `proapi.js`, `services.js` | Подгрузка платного контента: `POST /api/pro` с `initData`; права проверяет сервер. Обновление прав при старте |
| `ui-text.js`, `ui-pro-text.js`, `help.js` | Тексты RU/EN и контакты помощи |
| `config.js` | `miniAppLink`, `privacyUrl`, **`proPreview`** |
| `tests/` | 40 тестов: `npm test` (Node 22) |
| `pages.yml` | Необязательно: Pages настроен напрямую с ветки `main`, воркфлоу не нужен |

**`apiBase`** — адрес сервера оплаты (пусто = заглушка); **`refundDays`** — срок возврата на экране тарифов.

**Платный контент:** при заданном `apiBase` приходит с сервера (`/api/pro`), `proPreview` автоматически отключается. Без сервера бета-предпросмотр PRO (`proPreview: true`) показывает платные тексты только если рядом лежит `chitay_pro_full.json` (это копия `docs/chitay_pro_seed.json`; **в публичную сборку и в zip он не входит**; положив его на Pages для теста, вы делаете платные тексты видимыми всем по ссылке; после теста удалите). Без файла PRO-разделы покажут «предпросмотр не подключён».

**`proPreview: true`** открывает PRO-разделы на время бета-теста. Оплаты нет. Перед включением оплаты поставить `false`.

## Быстрая публикация на GitHub Pages (≈10 минут)
1. Создайте репозиторий на GitHub (бесплатные Pages требуют **публичный**), например `chitay-quiz`.
2. Загрузите **содержимое этой папки** в корень репозитория (ветка `main`), включая скрытый `.nojekyll`; файл `pages.yml` положите в `.github/workflows/` (или возьмите папку из `web_chitay.zip`, где это уже сделано).
3. Repo → Settings → Pages → Build and deployment → Source: **GitHub Actions**.
4. Вкладка Actions → дождитесь зелёного «Deploy to GitHub Pages». Адрес: `https://<ник>.github.io/chitay-quiz/`.
5. В @BotFather: `/newapp` (или Bot Settings → Menu Button) → указать этот адрес. Получите ссылку вида `https://t.me/<бот>/<short_name>`.
6. Откройте `config.js`: впишите `miniAppLink` (ссылка из п. 5) и, когда будет, `privacyUrl`. Закоммитьте, Pages обновится сам.

Без `miniAppLink` кнопки «Поделиться» отправляют ссылку на страницу Pages (она открывается и в браузере). С ним друзья попадают сразу в Mini App с вызовом (`startapp=c85`).

## Локальный запуск
```
python -m http.server 8080   # затем http://localhost:8080
```
Открывать файл двойным кликом нельзя: браузер блокирует загрузку JSON с `file://`.

## Проверка перед публикацией
- [ ] `npm test` зелёный (40 тестов).
- [ ] В названии, описании бота и канале нет слов «ложь», «детектор», «сканер».
- [ ] Контакты в `help.js` перепроверены (источники: `горячие_линии_источники.md`, дата 26.10.2026) и согласованы с юристом/НКО.
- [ ] Вычитка кейсов психологом и английских текстов носителем (статус в `chitay_quiz.json → meta.status`).
- [ ] Политика конфиденциальности опубликована, адрес в `privacyUrl`. Сервис не собирает данных: в браузере хранится только отметка возраста и лучший результат (`localStorage`). Сетевых запросов к вашим серверам нет; загружается только скрипт Telegram (`telegram.org`) и Pages.
- [ ] Реквизиты ИП (ФИО, ИНН/ОГРНИП, e-mail, дата) вносятся в политику на финальном шаге.

## Чего здесь нет (этап В)
Сервера, дуэлей с общим счётом, рейтинга, оплаты, аналитики. Вызов другу работает без сервера: результат друга передаётся в ссылке.
